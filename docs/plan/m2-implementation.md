## Phase A and B work order

1. Record the Windows compatibility evidence, its provenance, and the remaining gates.
2. Resolve trusted workspace and profile scope for New chat and exact Continue. Keep drafts with their conversation and check writer ownership.
3. Open or reveal one editor tab per conversation. Keep the transcript, composer and existing inspection views reachable.
4. Stream through the installed CLI with bounded framing, normal settings, fail-closed permission prompts and turn interrupt.
5. Confirm sends against provider acknowledgments and preserve recoverable drafts across tab changes. Block automatic retry when delivery is uncertain.
6. Run typecheck, tests, build, packaging and VSIX inspection before installation.
