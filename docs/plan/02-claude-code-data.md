# 2. Claude Code data sources and schema

[← 1](01-goal-and-scope.md) · [Plan index](README.md) · [3 →](03-codex-data.md)

## Local evidence and source selection

- Read filesystem metadata for 147 main transcripts across four project folders, 1,815 child transcripts with 1,815 metadata companions, 133 persisted-output files, and 251 temporary Bash task outputs. The deeper schema sample covered 19 main and 36 child transcripts from Claude Code 2.1.310–2.1.330. Some recent sessions exceeded 5 MB and the largest main transcript was about 42 MiB, so eager parsing of the full history would be expensive.
- A targeted sample of 100 child metadata files all had <code>toolUseId</code>. Three observed launch/result pairs in the targeted pass agreed across the spawning <code>tool_use.id</code>, child metadata <code>toolUseId</code>, and result <code>agentId</code>. Child status flags and late metadata are useful independently of parent output.
- The task-output headers needed for a full Claude-to-Codex match were unverified locally. Read-only checks confirmed the task-ID half of the link and the provider documentation confirmed a structured status-line path for Claude quota, detailed in [[§5](05-subagents-and-files.md)](05-subagents-and-files.md)–[[§6](06-usage-and-limits.md)](06-usage-and-limits.md). The user already has a command-type Claude status line configured. Its contents and output were not captured or executed.
- Verified the installed native Claude Code 2.1.330 version and rechecked main help and background command help. Main help confirms streamed I/O and subagent forwarding. <code>claude stop --help</code> confirms whole background-session scope. Help has no standalone quota flag and cannot verify the signed-in <code>/usage</code> result or targeted task cancellation. Context7 was unavailable, so the plan cites official provider documentation for these capabilities. Runtime tests belong to M1/M2 in disposable profiles. [Claude Code CLI reference](https://code.claude.com/docs/en/cli-reference) · [Claude Agent SDK for TypeScript](https://code.claude.com/docs/en/agent-sdk/typescript)

## Claude transcript records

These are top-level fields unless qualified. Metadata records may lack a timestamp or message ID. Preserve source order and the context provided by the owning file.

| Observed <code>type</code> | Fields used or identified | Timeline or state |
| --- | --- | --- |
| <code>user</code> | <code>uuid</code>, <code>parentUuid</code>, <code>sessionId</code>, <code>agentId</code>, <code>isSidechain</code>, <code>timestamp</code>, <code>cwd</code>, <code>gitBranch</code>, <code>version</code>, <code>message.role</code>, <code>message.content</code> string/array, <code>promptId</code>, <code>promptSource</code>, <code>turnOrigin</code>, <code>isMeta</code>, <code>isCompactSummary</code>, <code>sourceToolAssistantUUID</code>, <code>sourceToolUseID</code>, <code>toolUseResult</code>, <code>toolDenialKind</code>, <code>toolEndsTurn</code>. | Human prompt or local child task only when explicitly attributable. Tool results still arrive in <code>user</code> records and close tool cards. Exclude injected context and compact summaries from prompt counts and title extraction. |
| <code>assistant</code> | <code>uuid</code>, <code>parentUuid</code>, <code>sessionId</code>, <code>agentId</code>, <code>timestamp</code>, <code>apiBlockIndex</code>, <code>requestId</code>, <code>message.id</code>, <code>message.model</code>, <code>message.content</code>, <code>message.stop_reason</code>, <code>message.usage</code>, <code>effort</code>, <code>perTurnEffort</code>, <code>thinkingDurationMs</code>, <code>isAbortedMidStream</code>, <code>isApiErrorMessage</code>, <code>apiError</code>, <code>apiErrorStatus</code>. Other observed record shapes had <code>quotaLimits</code> as an optional key. | Group message blocks into the same response. Render text, calls, and safe error messages. Record actual model and usage once per provider response. The quota key has no verified account-window contract and does not power gauges. |
| <code>attachment</code> | <code>uuid</code>, <code>parentUuid</code>, <code>timestamp</code>, <code>agentId</code>, <code>attachment.type</code>. When <code>attachment.type</code> is <code>task_status</code>, observed fields include <code>attachment.taskId</code>, <code>attachment.taskType</code>, <code>attachment.description</code>, <code>attachment.status</code>, <code>attachment.outputFilePath</code>. File-shaped attachments include <code>attachment.filename</code> or <code>attachment.displayPath</code>. | Allowlist task status and sanitized attachment label only where attributable. Ignore rendered attachment bodies, credential and organization attachments, system reminders, instructions, hooks, environment, permission data, prompts injected by Claude, and tool registry data. File references count as attachments until a tool action shows a read or edit. |
| <code>queue-operation</code> | <code>operation</code>, <code>timestamp</code>, <code>sessionId</code>, <code>commandUuid</code>, <code>deliveryId</code>, <code>reason</code>, <code>content</code>. | Optional queued, delivered, or canceled hint for recognized operations. Correlate with a prompt once known. Skip general content and duplicate queued prompts. |
| <code>file-history-snapshot</code> | <code>messageId</code>, <code>isSnapshotUpdate</code>, <code>snapshot.messageId</code>, <code>snapshot.timestamp</code>, <code>snapshot.trackedFileBackups[path].backupFileName</code>, <code>version</code>, <code>backupTime</code>, <code>realParentDir</code>. | Index checkpoint evidence for Files and associate it with the related message. Do not open backup paths or infer an edit from a checkpoint alone. |
| <code>file-history-delta</code> | <code>messageId</code>, <code>snapshotMessageId</code>, <code>trackingPath</code>, <code>timestamp</code>, <code>backup.backupFileName</code>, <code>backup.version</code>, <code>backup.backupTime</code>, <code>backup.realParentDir</code>. | Update checkpoint metadata. Join on snapshot ID and deduplicate revisions. Prefer recorded Edit/Write results for applied changes. |
| <code>ai-title</code> | <code>aiTitle</code>, <code>sessionId</code>. | Latest nonempty sanitized display title in source order. |
| <code>last-prompt</code> | <code>lastPrompt</code>, <code>leafUuid</code>, <code>sessionId</code>. | Safe title fallback and leaf hint. Do not turn it into a duplicate chat message or let it reorder earlier turns. |
| <code>tools-used</code> | <code>tools[]</code>, <code>sessionId</code>. | Optional compact summary. Timeline counts come from actual observed tool calls. |
| <code>session-owner</code> | Account and organization ownership fields, <code>sessionId</code>. | Ignore the record for the UI and usage attribution. Never extract or persist the account or organization identifiers. |
| <code>atis-latch</code> | <code>atis</code>, <code>sessionId</code>. | Ignore internal state. |
| <code>api-request</code> | <code>id</code>, <code>querySource</code>, <code>shapeHash</code>, <code>params</code>, <code>tail</code>, <code>cacheControl</code>, <code>requestDigest</code>, <code>base</code>, <code>agentId</code>. | Drop the entire record. It can reproduce the model request. |
| <code>api-request-blob</code> | <code>hash</code>, <code>message</code>, <code>sessionId</code>, <code>agentId</code>. | Drop the entire record, including full prompt or response payloads. |
| <code>api-request-shape</code> | <code>shapeHash</code>, <code>shape</code>, <code>timestamp</code>, <code>version</code>, <code>agentId</code>. | Drop the entire record. |
| <code>system</code> | Observed <code>subtype=compact_boundary</code>, <code>uuid</code>, <code>logicalParentUuid</code>, <code>timestamp</code>, <code>compactMetadata</code>, <code>content</code>. | Show a quiet compacted-context marker. Keep existing recorded history and suppress injected content. |
| <code>mode</code> | <code>mode</code>, <code>sessionId</code>. | Optional recorded mode label in detail. No inference of live/idle or permissions from this alone. |
| <code>pr-link</code> | <code>prNumber</code>, <code>prUrl</code>, <code>prRepository</code>, <code>timestamp</code>, <code>sessionId</code>. | Optional PR number label. Do not fetch or automatically open the recorded URL. |

## Claude content and tool mappings

| Block or result | Observed fields | Rendering or indexing |
| --- | --- | --- |
| <code>text</code>, <code>thinking</code> | <code>text</code>, or <code>thinking</code> and <code>signature</code>. | Show genuine messages. A collapsed Thinking activity can show duration from the record when available. Keep raw internal reasoning and signatures out of rendered content. |
| <code>image</code>, <code>document</code> | <code>source</code>, optional <code>title</code>. | Show attachment kind and a safe name. Skip binary, remote source, and embedded payload. |
| <code>tool_use</code> | <code>id</code>, <code>name</code>, <code>input</code>, optional <code>caller</code>. | Start a collapsible tool card and index by logical lane plus ID. Generic tool rendering uses a label, state, and bounded vetted text. |
| <code>tool_result</code> | <code>tool_use_id</code>, <code>content</code> string or array, <code>is_error</code>. Observed result blocks <code>text</code>, <code>image</code>, <code>document</code>, <code>tool_reference.tool_name</code>. | Pair with the live or historical call. Show redacted text, an attachment indicator, or a safe tool label. Resolve known persisted-output references lazily. Use <code>sourceToolAssistantUUID</code> as a disambiguation hint when supplied. |
| <code>Read</code>, <code>Edit</code>, <code>Write</code> | <code>input.file_path</code>. Read has <code>offset</code> and <code>limit</code>. Edit has <code>old_string</code>, <code>new_string</code>, <code>replace_all</code>. Write has <code>content</code>. Observed result metadata <code>toolUseResult.filePath</code>, <code>oldString</code>, <code>newString</code>, <code>structuredPatch</code>. | Add file activity to Files and update its result state. Prefer the recorded patch. Use bounded old/new excerpts only when safely available. |
| <code>Bash</code> | <code>input.command</code>, <code>description</code>, <code>run_in_background</code>, <code>timeout</code>. Observed result fields <code>stdout</code>, <code>stderr</code>, <code>interrupted</code>, <code>backgroundTaskId</code>, <code>backgroundCwdHint</code>. | Render command, result, and available timing. Create a local task link for confirmed background results. An initial successful scheduling response represents launch only. |
| <code>Agent</code> | <code>input.description</code>, <code>subagent_type</code>, <code>model</code>, <code>effort</code>, <code>prompt</code>, <code>run_in_background</code> (accept legacy string/boolean forms). Observed result <code>agentId</code>, <code>status</code>, <code>isAsync</code>, <code>resolvedModel</code>, <code>outputFile</code>, <code>canContinueAgent</code>. | Add a child placeholder at spawn. Resolve its lane using the metadata and result IDs. Support older <code>Task</code> only if the input and child linkage match the legacy spawn shape. |
| <code>Glob</code>, <code>Grep</code>, <code>SendMessage</code>, <code>TaskStop</code> | <code>pattern</code>/<code>path</code> for searches, optional <code>glob</code> for Grep. Observed <code>to</code>/<code>recipient</code>, <code>summary</code>, <code>message</code>/<code>content</code> for SendMessage, <code>task_id</code> for TaskStop. | Show search, agent communication, or stop request. Search targets are lower-confidence file references. A stop request changes outcome only when its result or agent state confirms it. |
